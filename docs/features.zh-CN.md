# 产品功能说明｜这顿有解

[English](features.md) | **简体中文** · [返回 README](../README.zh-CN.md)

除特别标注为“未来功能”外，本文描述的是**现有业务实现**。微信小程序尚未正式公开发布。

## 外面吃：单独记录与按店铺连续记录

- 单独保存菜品：所属店铺、店铺地址、分类、吃过/想吃状态、堂食/外卖、评分、标签、价格、日期、备注和可选图片。
- 也可以**按店铺连续录入多道菜**，统一保留店铺信息。
- 已有店铺支持搜索自动补全；已有地址与新地址冲突时提示，不静默覆盖。
- 相关录入流程处理重复菜品，切换店铺类型时保留尚未保存的表单草稿。

## 店铺信息与类型

- 维护店铺名称、位置、整体评价、详情和店内菜品。
- 店铺类型为二级层次：固定一级、系统预设二级，以及用户自定义二级。
- 店铺最多可以选三个类型，用于后续筛选和抽店铺；类型为选填，不妨碍快速记菜品。
- 店铺属性不混入菜品自身的分类、评分等字段。

## 自己烧

- 记录做过或打算做的菜，保存独立分类、难度、制作时间、菜谱、备注、标签和可选图片。
- 独立的筛选与随机抽选，不把外食项目混入候选。

## 美食库与随机选餐

- 外食可按菜品/店铺浏览；支持搜索、筛选、编辑、删除和基础统计。
- **外食抽菜品：** 按吃过/想吃、菜品分类、就餐方式、最低评分、指定店铺等条件筛选。
- **外食抽店铺：** 独立候选池，支持店铺类型筛选及本轮已抽结果排除。
- **自己烧抽菜品：** 单独候选池和筛选。
- 扭蛋/揭晓动画负责展示业务逻辑已选出的结果，而非在动画中决定随机值。

## 微信身份、图片与一致性

- 微信静默登录、后端 code 交换、应用自身 Session 与用户权限隔离。
- 菜品可选图片，后端校验 MIME 和文件签名，存入 COS 私有桶；按需签名访问、图片替换/删除及失败回滚。
- 店铺/菜品批量保存使用事务；删除时区分数据库成功与外部媒体清理不完整。
- 微信文字内容安全接口在真实微信的本地联调流程中已使用。
- 微信**图片内容安全审核**具有异步提交、回调处理与自动化测试代码，但生产 HTTPS 回调验收尚未完成。

## 尚未开发：截图辅助自动录入

考虑未来支持上传**订单、团购等页面截图**，从中识别店铺名称、截图中存在的地址、菜品、数量、价格和套餐信息，再预填供用户检查的表单。

- 目前没有可使用的截图 OCR/视觉理解自动录入功能。
- 不是将普通菜品照片识别成菜单。
- 对不明确内容需要用户检查与补全，不能自动编造信息。
- 暂无确定开发日期。

现有手动录入、店铺管理、美食库和随机抽选功能不依赖该增强功能，已经能正常使用。

## 部署说明

私有源码支持本地、API/数据库、微信、COS 和生产配置。私有文档记录了后端部署/冒烟测试，但不意味着公开小程序已正式上架或剩余生产验收全部完成。
