# 项目状态｜求职作品集摘要

[English](project-status.md) | **简体中文** · [返回 README](../README.zh-CN.md)

**核心功能可用，微信小程序尚未正式发布。** 现有手动录入、管理和抽选可以正常工作；还没有面向所有用户公开上架。

本页只记录主要产品里程碑，不跟踪每一次私有仓库提交。

## 已开发并可用的产品功能

- 微信小程序外食、自己烧的新增、详情、修改和删除。
- 单独记菜品、同一店铺批量记菜品、店铺自动补全和地址冲突保护。
- 店铺详情和层级店铺类型选择，支持用户自定义二级类型。
- 美食库、搜索/筛选、统计以及三种抽选（抽店铺、外食抽菜品、自己烧）。
- Node.js/Fastify REST API、MySQL 数据关系/迁移/事务、应用 Session 和用户数据权限隔离。
- 真实微信身份与文字审核、私有 COS 图片的本地联调。
- 后端和前端自动化测试、本地 API 冒烟，以及已有部署配置与后端部署/冒烟记录。

## 与现有核心功能分开看待的事项

**1. 截图辅助自动填表：尚未开发，也没有确定排期。** 计划未来分析点餐/团购等截图，从可见内容中提取店铺、地址、菜品、数量、价格等并填入可编辑表单，最后由用户确认。主要目的是减少手动录入负担，不代表现有项目已经具备 AI 识图功能。

**2. 微信图片内容安全审核：另一项独立功能。** 异步提交、trace/回调匹配、状态更新等代码和测试已形成，但真实生产 HTTPS 回调仍未验收，不能表述为正式线上审核已全部打通。

**3. 正式上架及剩余验收。** 目前小程序没有公开发布。私有工程文档记录了后端部署与 smoke test，但不能据此推断所有云服务、生产数据库迁移、域名配置、上线安全检查和真机发布流程均已验收。

## 求职展示可验证的能力

- 可运行的多实体产品：店铺、菜品、类型、图文记录和随机抽选。
- API / 数据库设计、用户权限隔离、存储集成与失败一致性处理。
- 可切换环境、自动化测试与部署工程。
- 如实区分**已有产品能力**、**部署/联调证据**与**未来智能化功能**。

## 公开仓库边界

完整应用源码位于私有仓库。这里仅展示架构、技术决策和产品范围，不公开真实用户资料、含隐私的截图、私有图片、密钥、生产凭据、带签名的媒体 URL 等内容。

后续只有产品与上线里程碑发生实质变化时才同步更新。
